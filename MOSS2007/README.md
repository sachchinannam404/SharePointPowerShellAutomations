# MOSS 2007 scripts (archived)

**Status: archived / historical**

PowerShell samples that use the **MOSS 2007** server object model (many also noted as usable on early SharePoint 2010 farms).

## Caution

- **Not for Microsoft 365 / SharePoint Online.** These scripts expect on-premises assemblies and farm access.
- Run only on appropriate lab or legacy farms with full understanding of impact.
- Provenance includes community collections (see `Readme.txt` / `powershell.nu_moss2007_script_collection.txt`). Review every script before use.

## Prerequisites (legacy)

- SharePoint 2007 (or compatible 2010) farm  
- SharePoint Management Shell / snap-ins of that era  
- Farm or site collection administrator rights as required by each script
