Older or ad-hoc **SharePoint Online** scripts collected over time.

## Caution

- Quality and currency vary by file.  
- Auth may assume retired multi-tenant apps or Windows-only modules.  
- Prefer the **maintained** projects:
  - [`../CreateSiteCollections/`](../CreateSiteCollections/)

## Prerequisites

- PowerShell 7.4+ and current **PnP.PowerShell 3.x** when adapting scripts  
- Your own **Entra ID** application registration  
- SharePoint Admin or equivalent app permissions  

Always read the script header and test in a non-production tenant.
